1️⃣  STEP 1: DEPLOY BACKEND TO RENDER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open: https://dashboard.render.com/

2. Click: "New +" → "Web Service"

3. Select Repository:
   https://github.com/misbah003/demo
   (or your GitHub repo)

4. Configuration Values (COPY THESE):

   Name:
   navi-tax-ml-api

   Region:
   Frankfurt

   Runtime:
   Python 3.9

   Build Command:
   pip install -r requirements.txt

   Start Command:
   gunicorn -w 2 -b 0.0.0.0:$PORT --timeout 120 ml.ml_api_service_optimized:app

5. Plan: Free

6. Click: "Create Web Service"

7. Wait for deployment (15-20 minutes) → Status: "Live" (green)

8. Save your Render URL:
   https://navi-tax-ml-api.onrender.com
   (You'll get something like this)

3️⃣  STEP 3: UPDATE FRONTEND ENVIRONMENT

Find this line:

Replace with your Render URL if different.

Then commit:

git commit -m "chore: update backend URL for production"
git push
