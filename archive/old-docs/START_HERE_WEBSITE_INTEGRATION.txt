💻 INTEGRATION EXAMPLES
================================================================================

EXAMPLE 1: SIMPLE JAVASCRIPT
────────────────────────────────────────────────────────────────────────────
<script src="vat_predictor.js"></script>
<script>
async function calculateRefund() {
    const result = await VATPredictor.predict({
        amount: 100000,
        vatRate: 18,
        category: 'Electronics',
        state: 'Maharashtra',  // ← Use state name!
        annualTurnover: 5000000,
        riskScore: 0.2,
        compliance: 'Compliant'
    });
    
    alert('Refund: ' + VATPredictor.formatCurrency(result.predicted_refund_amount));
}
</script>

EXAMPLE 2: GET ALL STATES
────────────────────────────────────────────────────────────────────────────
<select id="state"></select>

<script src="vat_predictor.js"></script>
<script>
// Populate dropdown with all states
const states = VATPredictor.getStates();
const select = document.getElementById('state');

states.forEach(state => {
    const option = document.createElement('option');
    option.value = state;
    option.textContent = state;
    select.appendChild(option);
});
</script>

EXAMPLE 3: CONVERT STATE TO REGION
────────────────────────────────────────────────────────────────────────────
<script src="vat_predictor.js"></script>
<script>
const region = VATPredictor.stateToRegion('Maharashtra');
console.log(region);  // Output: 'West'
</script>

🔄 HOW STATE MAPPING WORKS
================================================================================

User Experience:
  1. User selects "Maharashtra" from dropdown
  2. Form looks beautiful and familiar
  3. User clicks "Predict VAT Refund"

Behind the Scenes:
  1. JavaScript captures: state = "Maharashtra"
  2. Automatic conversion: "Maharashtra" → "West"
  3. API receives: Region = "West"
  4. Prediction returned: ₹8,290.25
