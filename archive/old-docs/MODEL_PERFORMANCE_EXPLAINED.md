# 📊 Model Performance Explained (Simple Terms)

## 🎯 What is R² Score?

**R² (R-squared)** = How well the model predicts outcomes

Think of it as a **test score**:
- R² = 1.0 (100%) = Perfect predictions
- R² = 0.8 (80%) = Very good
- R² = 0.5 (50%) = Okay
- **R² = 0.258 (25.8%)** = Poor ← **Your model**
- R² = 0.0 (0%) = Useless (random guessing)
