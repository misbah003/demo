TECHNICAL DETAILS:
═══════════════════════════════════════════════════════════════════════════════

BEFORE:
-------
Backend Classification:
  if (lowerText.includes('return') || lowerText.includes('gst') || lowerText.includes('vat')) {
    return 'Tax Return';  ❌ Doesn't contain "VAT" as substring
  }

Edge Function Query:
  .ilike('type', '%VAT%')  ❌ Doesn't match "Tax Return"

Result: No documents found → Empty graph

AFTER:
------
Backend Classification:
  if (lowerText.includes('vat') || lowerText.includes('gst')) {
    if (lowerText.includes('return')) return 'VAT Return';  ✅ Contains "VAT"
    if (lowerText.includes('invoice')) return 'VAT Invoice'; ✅ Contains "VAT"
    return 'VAT Document';  ✅ Contains "VAT"
  }

Edge Function Query:
  .or('type.ilike.%VAT%,type.ilike.%Tax Return%,type.ilike.%Tax Invoice%,type.ilike.%GST%')
  ✅ Matches "VAT Return", "VAT Invoice", "Tax Return", "Tax Invoice", "GST Document"

Result: Documents found → Graph shows personalized predictions! 🎉
