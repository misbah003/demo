📋 WHAT THIS DOES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Organizes your cluttered project by moving unnecessary files to an
archive folder, leaving only essential files in the root directory.

✅ SAFE: Nothing is deleted, only moved to archive/
✅ REVERSIBLE: You can restore any file from archive/
✅ FAST: Takes less than 10 seconds
