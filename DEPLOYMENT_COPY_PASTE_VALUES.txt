================================================================================
IMPORTANT NOTES
================================================================================

1. RENDER URL PATTERN:
   Format: https://SERVICE-NAME.onrender.com
   NOT: https://SERVICE-NAME.render.com (this is wrong!)

2. WAIT TIMES:
   - Render: 15-20 minutes for deployment
   - Vercel: 10-15 minutes for deployment
   - First request: 5-10 seconds (cold start)

3. FREE TIER LIMITS:
   - Render: 750 compute hours/month (enough)
   - Vercel: Unlimited bandwidth
   - Supabase: 500 MB storage

4. If something doesn't work:
   - Check dashboards for error logs
   - Verify environment variables
   - Make sure URLs are correct
   - Wait for cold start (first request is slow)
   - Restart services if needed

5. IMPORTANT: Don't close the browser tabs with your URLs!
   You'll need them for testing and monitoring.
