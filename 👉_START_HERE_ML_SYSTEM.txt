                         🔄 INTEGRATION STEPS
================================================================================

After ML API is running, update your backend:

1. UPDATE server.js (Backend)
   
   Replace:
   function extractEntities(text) { /* regex */ }
   
   With:
   async function extractEntities(text) {
     const response = await fetch('http://localhost:8000/api/extract-entities', {
       method: 'POST',
       body: JSON.stringify({text})
     });
     return await response.json();
   }

2. UPDATE user-vat-forecast/index.ts (Edge Function)
   
   Replace:
   function generateUserBasedForecast(vatAmounts, ...) {
     const r2Score = vatAmounts.length >= 5 ? 0.75 : 0.55; // FAKE!
   }
   
   With:
   async function generateUserBasedForecast(vatAmounts, dates, ...) {
     const response = await fetch('http://localhost:8000/api/forecast-vat', {
       method: 'POST',
       body: JSON.stringify({amounts: vatAmounts, dates, forecast_months: 6})
     });
     const result = await response.json();
     return {
       predictions: result.forecast.predictions,
       accuracy: {
         r2_score: result.metrics.r2_score,  // REAL R²!
         mae: result.metrics.mae,
         rmse: result.metrics.rmse,
         mape: result.metrics.mape
       }
     };
   }

================================================================================
                         🐛 TROUBLESHOOTING
================================================================================

ISSUE: Installation fails
   SOLUTION: python -m pip install --upgrade pip
             Then retry: SETUP_ADVANCED_ML.bat

ISSUE: spaCy model not found
   SOLUTION: python -m spacy download en_core_web_sm

ISSUE: Prophet installation fails
   SOLUTION: pip install pystan
             pip install prophet

ISSUE: Out of memory during training
   SOLUTION: Reduce batch_size to 16 in training code

ISSUE: API not starting
   SOLUTION: Check if port 8000 is available
             netstat -ano | findstr :8000
