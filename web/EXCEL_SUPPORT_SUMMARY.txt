🎯 HOW TO USE:
═══════════════════════════════════════════════════════════════════

METHOD 1: Generate and Upload Sample Files
-------------------------------------------
Run this command:
  python sample_doc.py

This will:
  ✅ Generate 5 Excel invoice files
  ✅ Automatically upload them to the backend
  ✅ Process and extract data from each file
  ✅ Save results to the database

METHOD 2: Upload Through Web Interface
---------------------------------------
1. Open: http://localhost:8080
2. Login to your account
3. Navigate to document upload section
4. Upload your .xlsx or .xls files
5. View processed results in dashboard

METHOD 3: Manual API Upload
----------------------------
Use curl or Postman to POST to:
  http://localhost:3001/api/process-document
